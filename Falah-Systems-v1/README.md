# Falah Systems v1

نسخة نظيفة قابلة للتجربة على أي سيرفر Discord.

## الأنظمة الموجودة
- 🎫 مركز تذاكر بقائمة اختيار:
  - التفعيل
  - التقديم على الإدارة
  - المتجر
  - شكوى على لاعب
  - اعتراض على باند
  - دعم فني
  - مشكلة برمجية
  - دعم فني عام
  - التواصل مع الإدارة
- ⏳ نظام انتظار للاعبين.
- 👮 تسجيل دخول/خروج الإداري.
- ⭐ نقاط الإداري حسب مدة الجلسة.
- ⚠️ نظام مخالفات/تحذيرات بسيط مع سجل.
- 📊 سجل إداري اختياري.
- ⚙️ إعداد تلقائي بأمر `/setup`.
- لا يوجد Welcome أو Goodbye.

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. افتح المجلد في VS Code.
3. انسخ `.env.example` إلى ملف باسم `.env`.
4. ضع Token البوت و Client ID و ID السيرفر التجريبي في `.env`.
5. افتح Terminal داخل المجلد ونفذ:
   `npm install`
6. بعدها:
   `npm start`
7. داخل السيرفر نفذ:
   `/setup`

## مهم
قبل التجربة، أعطِ البوت صلاحيات مناسبة مثل:
- Manage Channels
- Manage Messages
- View Channels
- Send Messages
- Read Message History

واجعل رتبة البوت أعلى من رتبة الدعم إذا احتجت منه إدارة الرومات.

## تعديل الرتب
بعد `/setup` افتح `config.json` وضع:
- `supportRoleId`: ID رتبة الدعم.
- `adminRoleId`: ID رتبة الإدارة.

يمكن تعديل عدد الدقائق المطلوبة لنقطة من:
`points.minutesPerPoint`

وعدد نقاط إغلاق التذكرة من:
`points.pointsOnTicketClose`
